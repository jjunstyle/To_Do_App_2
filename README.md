# To-Do App

[클로드 코드를 활용한 바이브 코딩 완벽 입문] 첫 번째 프로젝트

React + TypeScript + Vite + Tailwind CSS로 만든 할 일 관리 앱입니다.

## 기능

- 할 일 추가/수정(더블클릭)/삭제/완료 처리
- 우선순위(높음/보통/낮음), 마감일 지정
- 전체/진행중/완료 필터, 검색
- 마감일 기준 정렬(지남/오늘 강조), 완료율 진행 바
- 라이트/다크/시스템 테마
- `localStorage`에 자동 저장 (별도 백엔드 없음)

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
